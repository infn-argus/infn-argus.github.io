# ARGUS organization homepage

The public entry point for the [INFN ARGUS organization](https://infn-argus.github.io/).
It links to the ARGUS project, Knowledge Hub, its getting started guide and its manuals.

This is a static GitHub Pages site. Open `index.html` to preview it locally. Text and
language-aware destinations are maintained in `script.js`; layout is in `styles.css`.

The site uses the ARGUS app icon under the same EUPL-1.2 license as the project site.
